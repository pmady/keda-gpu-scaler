# JOSS draft (September 2026)

Paper prepared for the Journal of Open Source Software in the JOSS
`paper.md` format. JOSS's scope requires evidence that the software is used
for research; keda-gpu-scaler is infrastructure and has no published research
use yet, so the submission (openjournals/joss-reviews#11319) was closed at the
scope check without review. The draft is kept here as a concise project
description.

The arXiv preprint in `../arxiv/` is the citable write-up of the design.
